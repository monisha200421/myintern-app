# MyIntern App

This is my internship project - A cross platform authentication app.

I have built this app using React Native with Expo and Supabase for backend authentication.

Link to App: https://myintern-app.vercel.app
GitHub: https://github.com/monisha200421/myintern-app

Features:
- User can Sign up with email and password
- User can Sign in
- Forgot password option
- Sign out

Technologies used:
- React Native, Expo
- Supabase for Authentication
- Vercel for hosting the web version

How to run the project:
1. npm install
2. npx expo start
3. For web: npx expo start --web

For Android testing I used Expo Go app to scan the QR code.
